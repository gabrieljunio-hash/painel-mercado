# Mercado Claro

Painel financeiro e agro brasileiro. Frontend em `index.html`.

O site atual possui cotação USD/BRL via AwesomeAPI, gráficos incorporados e simulador de juros compostos. Café, soja e boi abrem links externos; seus valores ainda não são importados automaticamente.

Cadastro, alertas em segundo plano e cobrança Premium ainda dependem de serviços externos e não estão ativos.
